# External Links
There are a couple of other sources that I use for managing worldbuilding. Those are all linked here for easy access.
## Azgaar Map Builder
[https://www.azgaar.com](https://azgaar.github.io/Fantasy-Map-Generator/) 

Used to create custom maps. I uploaded my initial Adobe Illustrator sketch as a Height Map and then edited it further from there. 

## Fantasy Calendar
[https://app.fantasy-calendar.com/calendars/c81b81ab4168d2374bd72262334c7775](https://app.fantasy-calendar.com/calendars/c81b81ab4168d2374bd72262334c7775)

A web-based app that allows custom creation of fantasy calendars. Used to display my calendar for Efthygra.

## Google Docs Directory Updater
[https://docs.google.com/document/d/1M8WsUbn7KXoSHXiHBpYogb0oXjwpMhoJdE1viNhZjVk/edit?usp=sharing](https://docs.google.com/document/d/1M8WsUbn7KXoSHXiHBpYogb0oXjwpMhoJdE1viNhZjVk/edit?usp=sharing)

Used to update my Directory List on the Landing Page. Instruction on how to update are in the doc.
